
# Конфигурационное управление

Практическая работа №2. Вариант №27.

## Цель проекта

Разработать консольную программу для анализа
и визуализации зависимостей пакетов Ubuntu APT.

## Этап 1. XML-конфигурация

Реализованы:
- Чтение параметров из XML.
- Проверка имени пакета.
- Проверка URL репозитория.
- Проверка пути к тестовому файлу.
- Проверка режима тестирования.
- Проверка фильтрации.
- Обработка ошибок XML и файлов.
- Автоматические тесты.

## Структура

- src/main.py — исходный код.
- config/config.xml — настройки.
- config/test_repository.txt — тестовый граф.
- tests/test_config.py — тесты.
- run.bat — запуск в Windows.

## Параметры XML

- package — имя анализируемого пакета.
- repository — URL или путь к файлу.
- test_mode — true или false.
- filter — подстрока для исключения пакетов.

## Запуск

Windows:

    run.bat

Или:

    python src/main.py

## Тестирование

    python -m unittest discover -s tests -v

## Пример тестового графа

    A: B C
    B: D
    C: D
    D:

## Основные функции

- get_required_text — чтение обязательного параметра.
- get_test_mode — проверка режима работы.
- get_repository — проверка источника данных.
- get_filter — проверка фильтра.
- main — чтение конфигурации и вывод параметров.
